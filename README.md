# 💪 Sobre o Projeto

A **Academia Corpo em Movimento Fitness** é uma landing page moderna, responsiva e focada em conversão, desenvolvida para apresentar a academia, seus serviços, estrutura e avaliações.

O projeto foi pensado para transformar a presença digital da academia em uma experiência mais profissional, moderna e atrativa para novos alunos.

A landing page utiliza uma estética **fitness premium**, combinando:

> 🏋️ Performance  
> 🔥 Energia  
> ⚡ Movimento  
> 🎯 Conversão  
> 🏆 Evolução

---

# 🎯 Objetivo

O principal objetivo do projeto é facilitar a conexão entre a academia e seus potenciais alunos.

A página foi desenvolvida para:

- 🏋️ Apresentar a academia
- 💪 Destacar os serviços
- 📸 Apresentar a estrutura
- ⭐ Exibir avaliações reais
- 📍 Mostrar a localização
- 📞 Facilitar o contato
- 💬 Direcionar clientes para o WhatsApp
- 📱 Oferecer uma ótima experiência no celular

# ✨ Animações e Interações

O projeto utiliza microinterações para tornar a navegação mais dinâmica.

### Scroll Reveal

Elementos aparecem suavemente conforme o usuário navega pela página.

```css
.reveal {
    opacity: 0;
    transform: translateY(30px);
    transition: 
        opacity 0.8s ease,
        transform 0.8s ease;
}

.reveal.active {
    opacity: 1;
    transform: translateY(0);
}
